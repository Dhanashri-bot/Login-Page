🔐 Simple Login Page
A basic login page built using HTML, CSS, and JavaScript.
This project validates user input on the client side — allowing access only if the username is abc and the password is 123.

🧠 Project Overview
A front-end login page created with simple and clean UI.
Implements client-side validation using JavaScript.
Shows a success message for correct credentials, and an error message otherwise.
Great for learning form handling, validation, and DOM manipulation.

🛠️ Technologies Used
HTML5 – for the login form structure.
CSS3 – for styling and layout.
JavaScript (Vanilla JS) – for form validation and logic.

✨ Features
✅ Login form with username and password fields.
✅ Validation using JavaScript (no backend).
✅ Displays success or error messages.
✅ Responsive design for different screen sizes.
✅ Predefined credentials:

Username: abc

Password: 123
